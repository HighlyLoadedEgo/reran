# reran

> Your agent already ran that. reran remembers.

Token-optimizing memoization + output-extraction layer for AI coding agents
(Claude Code, ZCode, Codex CLI, Cursor, OpenCode…). The agent's shell call comes
in; reran answers either `unchanged since turn N` (exact, FS-content-validated)
or a compact structured digest — instead of the raw 5,000-token dump.
